# Governance

## Project Stewardship

This project is maintained by the repository owners and designated
maintainers. They are responsible for reviewing contributions, managing
releases, and making decisions about the project's direction.

## Decision Making

Maintainers seek consensus in issues and pull requests. When consensus cannot
be reached, the repository owners make the final decision after considering
the technical and community feedback available.

## Changes to Governance

Changes to this document should be proposed through a pull request and
reviewed like any other project change.
