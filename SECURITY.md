# Security Policy

## Supported Versions

Security fixes are provided for the latest version on the `main` branch.
Older versions may not receive security updates.

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues.

Use [GitHub's private vulnerability reporting](https://github.com/MaxAndreev27/docker/security/advisories/new)
to send the details privately. Include:

- A description of the vulnerability and its potential impact.
- The affected component and version or commit.
- Reproduction steps or a proof of concept, if available.
- Any suggested mitigation.

You should receive an acknowledgement within seven days. We will investigate,
keep the reporter informed when practical, and coordinate disclosure after a
fix or mitigation is available.
