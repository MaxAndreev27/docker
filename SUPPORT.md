# Support

## Questions and Troubleshooting

Before asking for help:

- Read the root, API, and frontend README files.
- Check existing issues for known problems and workarounds.
- Confirm that Docker, Docker Compose, Node.js, and npm meet the versions
  required by your environment.

For a new support request, open a GitHub issue and include:

- Your operating system and relevant tool versions.
- The command you ran.
- The complete error message and relevant logs.
- Minimal steps to reproduce the problem.
- The Docker Compose file or configuration involved, with secrets removed.

Do not include passwords, API keys, connection strings, or other sensitive
information in issues. Security vulnerabilities belong in the private process
described in [SECURITY.md](SECURITY.md).
